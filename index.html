Сеть, которая сама является шифром

Ключ разворачивается гиперсетью в целую обратимую нейросеть. Причинное внимание не усредняет токены — оно порождает коэффициенты унимодулярного треугольного оператора. Каждый токен преобразуется биективной S-подстановкой, замороженных половин нет, определитель оператора равен единице. Обратимость — свойство самой сети, а не внешней оболочки. Длина выхода равна длине входа при любом L.

Структура оператора

унимодулярная треугольная матрица

Матрица зависимостей причинного внимания: строка — целевой токен, столбец — источник. Заполнена только нижняя треугольная часть, диагональ — биективная S-подстановка. Определитель равен единице, поэтому оператор обратим при любых коэффициентах.

Порядки стадий

прямой обратный stride из ключа
Стадия 0 идёт по прямому порядку, стадия 1 — по обратному, дальше — ключевой stride, взаимно простой с длиной. За две стадии каждый токен зависит от всех остальных: дальнодействие обеспечено структурно, а не глобальными токенами.

Сравнение двух текстов

Чистый выход сети в сыром режиме: без nonce и дополнения, длина равна длине текста в байтах.

Исследовательская конструкция. Сырой режим детерминирован: равные сообщения дают равный шифротекст, целостность не обеспечивается — для этого есть аутентифицированный режим с nonce и HMAC. Биективность доказана конструктивно, криптостойкость не доказана и требует публичного дифференциального и линейного анализа. Не является стандартом.
