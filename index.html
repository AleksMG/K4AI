Формулы

T[n−1] = 0; T[i] = (T[i+1] + №кольца(P[i+1])) mod N
w = (v + №k_j + T[i]) mod N
a = (№P + u) mod N; L = кольцо[a]
b = (№L + w) mod N; C = кольцо[b]
ход: u ← u + Δu(C); v ← v + b; j ← j + (b нечётно ? 2 : 1)

Кольцевая перестановка σ применяется дважды за виток: C = σ(σ(p+u) + w). Между применениями — сдвиг, поэтому виток не сводится к сложению ключа с буквой. Подача T тянет влияние буквы влево, ход стрелок от шифробуквы — вправо. Отсюда лавина в обе стороны за один виток.

Никаких байтов: только номера букв и сложение по модулю N. Служебных букв нет — длина шифровки равна длине текста по буквам.

04

Полевые заметки

Пароль. Одно слово, не менее пяти букв и четырёх разных. Согласуется устно, на посылку — один пароль. Кольцо строится из пароля и является ключом: носить его вместе с шифровкой нельзя.

Счёт. Две строки на бумаге: подача T под открытым текстом, шифровка под ней. Три счётчика u, v, j ведутся скрепками по полосам чисел. Шаг Δu и чётность позиции напечатаны в таблице кольца — считать их в уме не нужно.

Объём. До двухсот букв на пароль. Пишите телеграфно: «СНЕГ СЕВЕР ВЫХОД ЗАВТРА» вместо фразы. Ошибка в одной букве портит текст в обе стороны — это цена полной лавины.

Чего здесь нет намеренно. Ни контрольных букв, ни замков, ни служебных полей: всё это давало взломщику готовые пары «открытый–шифр» в предсказуемых местах. Проверки целостности нет — неверный пароль или искажение дадут мусор без предупреждения. Сверяйте смысл полученного текста.

Стойкость. Против частотного анализа, Касиски и линейных систем по известному открытому тексту конструкция держится: гамма непериодична, виток неаффинен. Против машинного анализа на больших объёмах гарантий нет — это ручной шифр, а не замена современной криптографии.

Для квеста. Распечатайте страницу: кольцо и шифровка уйдут на лист, пароль передайте отдельно. Алфавит можно задать свой — хоть из символов карты или значков легенды.
